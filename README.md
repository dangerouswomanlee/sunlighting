## ✨ 주요 기능

### 1. 홈페이지 `/`
- **이미지 자동 슬라이더** — 3초 간격 자동 전환, 좌우 버튼으로 수동 전환 가능
- **조명 종류 소개** — 경관 조명, 드롭형 조명, 라인 조명, 외벽 연출 조명, 조명 조형물, 크리스마스 트리
- **회사 소개 섹션** — 경관 조명 전문, 안전 시공, 맞춤형 디자인 3가지 강점 소개

### 2. 포트폴리오 `/portfolio`
- **시공 사례 갤러리** — 16개 프로젝트 카드 목록 표시
- **상세 페이지** — 프로젝트별 이미지 최대 10장 자동 로드 (`1.jpg ~ 10.jpg`)
- **이미지 팝업** — 클릭 시 확대 보기

**등록된 시공 사례 (16건)**

> 강남 데이터센터 · 강원랜드 하이원 리조트 · 과천 계룡건설 · 금성백조 · 금성백조 예미지 · 대구 중앙로역 푸르지오 · 대전 SBS 아카데미 · 대전 코오롱건설 · 대전 현대아울렛 · 발왕산 용평리조트 · 부산 덕천 포레나 · 소공동 롯데백화점 · 소공동 영프라자 · 왕길역 푸르지오 · 정동진 리조트 · 힐스테이트 푸르지오 주안

### 3. 문의 게시판 `/contact`
- **문의 목록** — 최신순 정렬, 키워드 검색, 답변 여부(미답변 / 답변 완료) 표시
- **문의 작성** — 제목, 작성자, 전화번호, 이메일, 비밀번호, 내용 입력
- **비밀번호 인증** — 본인이 작성한 문의만 내용 열람 가능
- **이메일 알림** — 관리자 답변 등록 시 작성자 이메일로 자동 발송 (Naver SMTP)

### 4. 관리자 페이지
- **JWT 기반 인증** — 쿠키에 JWT 저장, 세션 고정 공격 방지
- **로그인 시도 제한** — 일정 횟수 초과 시 10분 차단 (Brute-force 방어)
- **전체 문의 목록 관리** — 키워드 검색, 문의 상세 조회
- **답변 등록 / 문의 삭제** — 답변 등록 시 자동 이메일 발송

## 🚀 로컬 실행 방법

### 사전 준비

- Java 17+
- Maven

### 1. 저장소 클론

```bash
git clone https://github.com/dangerouswomanlee/sunlighting.git
cd sunlighting
```

### 2. 서버 실행

```bash
./mvnw spring-boot:run
```

로컬에서는 H2 인메모리 DB가 자동 사용됩니다.

### 3. 브라우저에서 확인

| URL | 설명 |
|-----|------|
| `http://localhost:10000` | 홈페이지 |
| `http://localhost:10000/portfolio` | 포트폴리오 |
| `http://localhost:10000/contact` | 문의 게시판 |
| `http://localhost:10000/h2-console` | H2 DB 콘솔 (로컬 전용) |

#### H2 콘솔 접속 정보

```
JDBC URL  : jdbc:h2:mem:testdb
Username  : sa
Password  : (없음)
```

## 🔒 보안 구조

- **관리자 URL 난독화** — 추측하기 어려운 경로로 관리자 페이지 접근 차단
- **JWT 인증** — 로그인 성공 시 JWT를 HttpOnly 쿠키에 저장, `AdminAuthInterceptor`로 매 요청 검증
- **Brute-force 방어** — `LoginAttemptService`로 로그인 실패 횟수 추적, 초과 시 10분 차단
- **세션 고정 공격 방지** — 로그인 시 기존 세션 무효화 후 새 세션 발급
- **CSRF 보호** — `HttpSessionCsrfTokenRepository` 적용
- **보안 헤더** — `SecurityHeaderFilter`로 X-Frame-Options 등 보안 헤더 추가
- **에러 정보 차단** — stacktrace, message 노출 비활성화
